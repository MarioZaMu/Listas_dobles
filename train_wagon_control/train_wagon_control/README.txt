CONTROL DE VAGONES - Lista doblemente enlazada (Python)

Como usarlo
1. Haz doble clic en index.html (se abre en el navegador).
   No hay que instalar nada. Todo el CSS y el JavaScript estan dentro del mismo archivo.
   La primera vez necesita internet: Python corre dentro del navegador (Pyodide).

Archivos
- index.html : interfaz + la logica en Python (Pyodide).
- train.py   : la lista doble (Wagon y Train). Se prueba sola con:  python train.py
- bridge.py  : conecta la interfaz con la lista (ya esta incluido dentro de index.html).

Metodos
append, prepend, insert, remove, traverse_to_index, print_list
+ go_next, go_prev, go_head, go_tail para recorrer en ambas direcciones.
